为什么现在：Shopify 在 2026 年 4 月推出官方 AI Toolkit 把平台上下文喂给编码 Agent，Dev MCP 补上 Liquid 文档与校验，同时 5 月开始对未签名的 bot/agent 收紧 Storefront API 与店面页面的限流、要求走 Web Bot Auth。一边邀请 Agent 进来写代码，一边给 Agent 访问店面装上身份闸机——这是平台第一次把'谁是 Agent'当成基础设施问题来处理，窗口期就是现在各家 Agent 还没完成身份接入的这几个月。
