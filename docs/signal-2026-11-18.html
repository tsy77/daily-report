#1

旧版客户账户强制迁移：商家需迁移到新版 Customer Accounts，并补回旧主题里的自定义功能

8/10

为什么现在：旧版客户账户已停止新店和未使用店铺开通，Shopify 表示会在 2026 年内公布最终下线日期。现在已到 2026 年 11 月，存量商家的迁移窗口正在收窄。同时 Web Pixels、退货自助、多语言 @inContext 和配置变更 webhook 都在补齐新版账户的能力，迁移后有空白需要应用来填。

可能产品：新版客户账户迁移助手：扫描主题中旧版账户的 Liquid 定制（如会员等级、订单查看、重新下单），一键生成等价的 Customer Account UI Extension；附带账户页埋点和自助退货模板。

今日验证动作：在 Shopify Community 和 Reddit r/shopify 搜索 'legacy customer accounts' 和 'new customer accounts missing'，统计商家抱怨最多的缺失功能 Top 5；再查 App Store 里 customer accounts 类应用的评论数和差评点。

#2

API 破坏性变更频繁：幂等键强制、REST 转 GraphQL、字段废弃，导致应用和自建集成静默出错

7/10

为什么现在：库存调整和退款类 mutation 的幂等键已从可选变为强制；REST 接口返回的 ID 改为 media GID；cart 收货地址改为必填的新结构；CDN 文件替换后不再主动清缓存。每个季度的 API 版本都在累积破坏性变更，中小开发者和自建集成的商家很难跟上。

可能产品：Shopify API 升级体检工具：接入代码仓库或 API 调用日志，自动标出即将失效的调用（缺少幂等键、使用已废弃字段、依赖旧 REST 资源），生成修复 diff 并在版本截止前提醒。

今日验证动作：在 GitHub 搜索调用 inventoryAdjustQuantities 或 refundCreate 但没有传 idempotency 参数的开源 Shopify 项目，统计受影响数量；同时到 Shopify 开发者论坛统计 'idempotency' 和 'API version upgrade broke' 相关帖子的数量。

#3

多仓库存与跨境合规收紧：按市场区域限购、HS 编码、税码废弃，商家容易卖出发不了的货或报错关

7/10

为什么现在：Shopify 已移除“从所有地点销售”设置，购物车限购改为按买家所在市场区域的可用库存计算；履约订单支持多重暂扣。在税务侧，ProductVariant.taxCode 随 Avalara 应用一并废弃，HS 编码支持全球默认值。多仓和跨境卖家的配置复杂度明显上升。

可能产品：跨境履约合规检查器：按市场检查每个 SKU 的可售库存覆盖、发货区配置缺口和 HS 编码缺失，并用 AI 批量推荐 HS 编码和税务分类，在发货暂扣时给出原因看板。

今日验证动作：随机抽 20 家多市场 Shopify 独立站，测试在不同国家能否加购和结算，记录“显示有货但无法下单”的比例；同时到 App Store 搜 HS code 类应用，看安装量和差评。

#4

AI 原生开发 Shopify 应用和主题：MCP、Dev Assistant 和 ShopifyQL 让小团队也能交付复杂功能

7/10

为什么现在：Shopify Dev MCP 已支持 Liquid 校验和 Functions 代码生成；ShopifyQL 可通过 GraphQL Admin API 查询全部分析数据。官方正在推动“AI 写 Shopify 代码”的工作流，但目前仍偏向开发者，商家侧几乎还没有面向非技术人员的工具。

可能产品：面向商家的自然语言数据分析和小功能生成器：用 ShopifyQL 回答“上周哪个渠道复购最高”这类问题，再借助 MCP 生成 Liquid 小改动或 Functions 折扣规则，一键预览后部署。

今日验证动作：用 Shopify Dev MCP 加 Claude 实测生成 3 个常见 Liquid 改动和 1 个折扣 Function，记录成功率和耗时；同时在 X 和 Reddit 搜 'ShopifyQL' 和 'Shopify MCP'，看讨论热度和需求方是谁。

#5

退款改发店铺余额、礼品卡、折扣场景化：商家想用资金留存替代现金退款

6/10

为什么现在：Shopify 已原生支持把退款发为店铺余额，并可与原路退款组合；可查询礼品卡上限；折扣新增 context 字段，可区分不同的适用资格；新增 Unlisted 状态，可用于隐藏的专属商品。资金留存所需的底层能力已经齐全，但商家缺少一个把它们组合起来的策略工具。

可能产品：退款转余额留存引擎：在退货流程中自动提供“改领店铺余额并加赠 10%”的选项，结合 Unlisted 专属商品和定向折扣做二次转化，并报告挽回的现金流。

今日验证动作：访谈 5 位月退货 100 单以上的 Shopify 卖家，问当前现金退款占比和是否愿意用加赠余额换取不退现金；再查 Loop、Rise.ai 等竞品的定价和差评。
